Changelog

ℹ

The revival branch is an active development branch started in 2026 that picks up from the original 2014 codebase. The original commits (2014) established the core data model and UI; the revival commits (2026) added features, fixed bugs, and added this documentation site.

Revival Branch (2026)

ℹ

All entries below correspond to commits on the revival branch. Commit hashes link to GitHub.

2026-06-13 5703dc0 Thorough rewrite of all BlupiEdit web documentation
  • Complete rewrite of the web documentation site (web/)
  • Revised and expanded all 6 HTML pages (Overview, Architecture, BLP Format, Item Types, Tiles & Sprites, API Reference)
  • Added auto-generated sidebar TOC, hamburger mobile nav, multi-column footer
  • Added hero buttons, UI overview diagram, keyboard shortcuts, CLI usage, license section
  • Added new standalone pages: Game Context, Contributing, Troubleshooting, FAQ, Changelog, 404
  • Added light/dark theme toggle with localStorage persistence
  • Added keyboard navigation for search, copy button fix, print stylesheet
2026-06-13 a590eeb Add comprehensive HTML documentation site (web/)
  • Initial creation of the web/ documentation site with 6 HTML pages
  • Shared CSS stylesheet with dark theme, custom properties, responsive layout
  • Shared JavaScript: search index, tabs, copy buttons, back-to-top, active nav, fade-in
  • Sidebar with auto-highlighted scroll position
2026-05-31 8790a42 Add LevelViewModel and object selection with highlight in object panel
  • Added LevelViewModel class as a PropertyGrid wrapper for level-wide metadata
  • Clicking an object in the Object Panel now selects it and highlights it in yellow
  • Selected LevelItem is shown in the PropertyGrid on the Objects tab
2026-05-14 238304c Several issues were fixed
  • Rewrote LevelData.cs: added full binary parsing for all known header fields, tile grids, and the 200-item array; introduced TileInfo, Sprite, Extensions, and LevelViewModel types
  • Added tilePanel_Paint, objectPanel_Paint, and objectPanel_MouseClick to MainForm.cs; implemented GDI+ rendering pipeline with chroma-key transparency and parallax background
  • Fixed LevelSelectForm.cs: level name is now read from 0x0178 and displayed in the level browser list
  • Added CMakeLists.txt for Linux/Mono build support
  • Added .gitignore for build output directories

Original Codebase (2014)

ℹ

The original codebase was written in 2014 and is the foundation of the revival branch. It established the core data model, UI layout, and binary file parsing.

2014-10-16 db1cf53 Fix major/minor version loading
  • Corrected byte offsets for reading MajorVersion and MinorVersion from .blp files
2014-06-22 d589b95 Adding more controls
  • Introduced TileList.cs and TileList.designer.cs — a new custom UserControl (333 lines) implementing the scrollable tile-picker grid with mouse selection and ItemDrag event
  • Added LevelData.cs stubs for LevelItem struct and ItemTypes enum (14 new lines)
  • Updated MainForm.Designer.cs extensively (155 lines changed): added splitContainer1/splitContainer2, wired up TileList and PropertyGrid panels, adjusted panel layout
  • Added MainForm.resx with image resources for the new controls
2014-06-21 dfedb83 Add menu events and basic Tiles/Objects tab controls
  • Wired up File → Open Game and Level → Change Level menu items with event handlers in MainForm.cs
  • Added horizontal and vertical scrollbars to the tile and object panels
  • Expanded LevelSelectForm.cs: level grid now populates from the game directory, Open/Save buttons fire DialogResult correctly
  • Extended MainForm.Designer.cs with 121 new lines: split containers, scroll bars, and panel size configuration
2014-06-21 ca19340 Add TabControl and title bar text
  • Added the three-tab TabControl (Tiles, Objects, Properties) to MainForm
  • Title bar now displays the application name and loaded EXE path
2014-01-30 36b254b Add default level file, complete level selection dialog
  • Added embedded DefaultLevel.blp resource used when no file is found on disk
  • Completed LevelSelectForm: level set list, level list, miniature preview
2014-01-19 c0720e4 Initial Commit
  • Initial project structure: BlupiEdit.sln, Program.cs, MainForm.cs, LevelData.cs
  • Core binary parsing of .blp level files and BLUPI.EXE sprite metadata
  • Basic TileList custom control with keyboard navigation
