TileList : UserControl

File: BlupiEdit/TileList.cs | Namespace: BlupiEdit

Custom scrollable tile-picker control. Renders a grid of tile bitmaps, supports mouse selection and keyboard navigation, and fires events on selection and drag. Marked [DefaultEvent("SelectedIndexChanged")].

Properties

MemberTypeDefaultDescription
SelectedIndexint { get; set; }−1Zero-based index of the selected tile. Setting scrolls the view to ensure visibility and fires SelectedIndexChanged. [Browsable(false)].
ImageSizeint { get; set; }8Display size of each tile in pixels. Tile cell size = ImageSize + 4 (4 px padding). Triggers ChangeSize() when set. In BlupiEdit, set to 64 for Object tiles.
DirectionDirection { get; set; }VerticalLayout direction. Vertical — tiles flow across rows, scrollbar on right. Horizontal — tiles flow down columns, scrollbar at bottom.
ImagesList<Bitmap>emptyList of tile bitmaps to display. Must call ChangeSize() after modifying.
ScrollValueint { get; set; }0Current scroll position in pixels. Clamped to [0, scrollBar.Maximum]. [Browsable(false)].

Events

EventTypeFires when
SelectedIndexChangedEventHandlerSelection changes (mouse click or keyboard). Also fires when SelectedIndex is set programmatically.
ItemDragEventHandlerMouse moves beyond SystemInformation.DragSize from the initial click position while left button held.

Methods

MethodReturnDescription
ChangeSize()voidRecomputes scrollbar maximum based on Images.Count, ImageSize, and control dimensions. Call after modifying Images or after the control is resized.
GetItemAtPoint(Point)intReturns the tile index at the given client coordinates, accounting for scroll offset and Direction. Returns Images.Count - 1 if the point is past the last tile.
GetItemBounds(int index)RectangleReturns the client-space rectangle of the tile slot at index, accounting for scroll offset and Direction. Returns Rectangle.Empty if direction is unknown.

Layout mathematics

The cell size is always actualImageSize = ImageSize + 4. For Direction.Vertical:

tilesPerRow = (controlWidth - vScrollBar.Width) / actualImageSize
numRows     = ceil(Images.Count / tilesPerRow)
scrollMax   = numRows × actualImageSize - controlHeight

For Direction.Horizontal:

tilesPerCol = (controlHeight - hScrollBar.Height) / actualImageSize
numCols     = ceil(Images.Count / tilesPerCol)
scrollMax   = numCols × actualImageSize - controlWidth

Tile index calculation for hit-testing (Vertical direction):

column = min(clickX / actualImageSize, tilesPerRow)
row    = (clickY + scrollValue) / actualImageSize
index  = row × tilesPerRow + column

Keyboard navigation

The control intercepts arrow keys, Home, End, PageUp, PageDown via PreviewKeyDown. For Direction.Vertical:

KeyAction
↓Move down one row (SelectedIndex += tilesPerRow)
↑Move up one row (SelectedIndex -= tilesPerRow)
→Move right one tile (SelectedIndex += 1)
←Move left one tile (SelectedIndex -= 1)
HomeJump to first tile
EndJump to last tile
PageUp / PageDownMove by one full page of rows

Sprite (struct)

File: BlupiEdit/LevelData.cs | Namespace: BlupiEdit

Value type pairing a Bitmap with its render offset. See Tiles & Sprites → Sprite for the full member table.

public struct Sprite
{
    public Point  Offset;   // draw offset
    public Bitmap Image;    // cropped bitmap (reference type)
    public int X { get; set; }   // Offset.X
    public int Y { get; set; }   // Offset.Y
    public int Width  { get; }    // Image.Width
    public int Height { get; }    // Image.Height
    public Size      Size   { get; }  // Image.Size
    public Rectangle Bounds { get; }  // Rectangle(Offset, Size)
}
