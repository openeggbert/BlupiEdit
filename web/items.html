Item Types

Complete reference for the ItemTypes enum — every game object that can appear as a LevelItem in a Speedy Blupi II level.

ℹ

Item type IDs are stored as uint16 in the .blp file at byte offset 0x00 of each 48-byte item record. ItemTypes.None (0) marks an unused slot and is never loaded into the Items list.

Overview

Items fall into five broad categories:

  • Platforms & Vehicles — moving objects Blupi can ride or interact with
  • Enemies — hostile creatures that kill Blupi on contact
  • Collectibles & Power-ups — items Blupi picks up for benefit
  • Hazards & Explosives — stationary or triggered danger objects
  • Special / Effects — goals, spawners, animation-only objects

All items share the same 48-byte LevelItem structure. The Type field determines how the game engine interprets the remaining fields (PointA/B, ABTime, ArtFile, etc.).

Goal (7) is the level exit door, placed at PointA. Explosion variants (8–11) represent the four frames of an explosion animation — they are placed as objects to mark where an explosion should occur. Effect items like Splash (14), Bubbles (15), and Sparkles (27) are purely decorative animations.

Item Movement System

All moving items share the same set of timing fields. The game engine computes the interpolated position at each tick:

// Conceptual movement logic (not in BlupiEdit — game engine only)
Position = Lerp(PointA, PointB, ticksElapsed / ABTime);

// State machine:
// 1. Wait at A for AWait ticks
// 2. Move to B over ABTime ticks
// 3. Wait at B for BWait ticks
// 4. Move back to A over BATime ticks
// 5. Repeat

The speed properties in LevelItem are computed from distance and time:

// pixels per game tick
ABSpeed = Math.Round(Distance(PointA, PointB) / ABTime);

In the renderer, item sprites are drawn with:

Sprite[] sprites = LevelData.TileImages[item.ArtFile];
if (item.Tile < sprites.Length)
    gfx.DrawSprite(sprites[item.Tile], item.PointA - new Size(scrollX, scrollY));
